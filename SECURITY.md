# Security Policy

## Supported versions

Only the latest published minor release receives security fixes. Before the first
public registry release, security fixes apply to the default branch only.

## Reporting a vulnerability

Do not open a public issue containing vulnerability details, credentials, customer
data, or exploit code.

Prefer GitHub's private vulnerability-reporting form for this repository:

https://github.com/Alpha-Centauri-Cyberspace/kite-sdk/security/advisories/new

If that form is unavailable, email `ops@getkite.sh` with the subject
`Kite SDK security report` and include the affected package/version, impact,
reproduction steps, and a safe way to contact you. Do not include real Kite tokens
or other production credentials.

Maintainers should acknowledge a report within three business days, coordinate a
private fix and release, and credit the reporter when requested and safe to do so.
